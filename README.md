# Blackjack

- Creates a game of Blackjack! 🃏🃏

- The dealer(CPU) and the User will each start with 2 cards.

- The dealer only shows 1 card to start while the user will get 2 cards.

- The User will then go first: Having the option to get a Blackjack off the first 2 cards, Hit, or Stand.

- If the User gets a Blackjack they win and if they go over 21 they lose.

- Once the User has played and finished, the Dealer will then play.

- The dealer will always draw a card if they are under a total score of 17.

- The goal is to get as close to a total score of 21 as possible, which then declares the winner!
